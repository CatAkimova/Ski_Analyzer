## 📋 Краткое резюме проекта

**Что это:** Веб-приложение для анализа техники катания на лыжах

**Как работает:**
1. Пользователь загружает видео → API принимает файл
2. Бэкенд обрабатывает видео (Python-модуль `ski_analyzer/`)
3. Система анализирует позу и сравнивает с эталоном
4. Возвращает результаты: балл, анализ углов, рекомендации
5. Фронтенд отображает результаты пользователю

**Что уже готово:**
- ✅ Python-модуль для обработки (`ski_analyzer/core/pipeline.py`)
- ✅ Анализ техники и сравнение с эталоном
- ✅ Генерация рекомендаций

**Что нужно сделать:**
- ⬜ REST API (бэкенд)
- ⬜ Веб-интерфейс (фронтенд)
- ⬜ Интеграция Python-модуля с API

## 🎯 Минимальный функционал (MVP)

### Бэкенд:
- `POST /api/v1/analyze` - загрузка видео
- `GET /api/v1/status/{task_id}` - статус обработки
- `GET /api/v1/result/{task_id}` - результат анализа

### Фронтенд:
- Страница загрузки видео
- Отображение прогресса
- Страница с результатами
