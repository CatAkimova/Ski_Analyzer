# Инструкция по тестированию

## 🧪 Проверка работоспособности

### 1. Проверка импортов

```bash
python -c "from ski_analyzer.core.pipeline import SkiAnalysisPipeline; print('OK')"
```

Если ошибок нет - модули установлены правильно.

### 2. Проверка построения эталона

```bash
python process_video.py --build-template
```

Должен создать/обновить `results/template_angles.csv`

### 3. Тестовая обработка видео

```bash
# Простая обработка (без анализа)
python process_video.py "Ski.Videos/User/User1.MOV"

# С анализом
python process_video.py "Ski.Videos/User/User1.MOV" --analyze
```

### 4. Сравнение со старым подходом

Для проверки корректности можно сравнить результаты:

**Старый подход:**
```bash
python test_pose_auto.py          # Создает landmarks
python analyze_angels_auto.py      # Создает angles
python resample.py                 # Создает resampled
python analyze_user.py             # Анализ
```

**Новый подход:**
```bash
python process_video.py "video.mp4" --analyze --save-all
```

Сравните результаты - они должны совпадать (с учетом округления).

## 🔍 Отладка

### Проблема: Модель YOLO не найдена

**Решение:** Убедитесь, что файл `yolov8n-pose.pt` находится в корне проекта.

### Проблема: Эталон не найден

**Решение:** 
```bash
python process_video.py --build-template
```

### Проблема: Импорты не работают

**Решение:** Убедитесь, что вы в корневой директории проекта:
```bash
cd C:\Users\User\PycharmProjects\PythonProject3
python process_video.py ...
```

### Проблема: Видео не обрабатывается

**Проверьте:**
1. Путь к видео правильный
2. Видео в поддерживаемом формате (mp4, mov, avi)
3. YOLO модель загружается корректно

## 🐛 Известные ограничения

1. **Обработка одного человека:** Система обрабатывает только первого обнаруженного человека в кадре
2. **Формат видео:** Рекомендуется mp4, но поддерживаются и другие форматы
3. **Размер видео:** Большие видео могут обрабатываться долго (рассмотрите очередь задач)

## 💡 Советы

- Для тестирования используйте короткие видео (10-30 секунд)
- Проверяйте промежуточные файлы (`--save-all`) для отладки
- Логи выводятся в консоль - следите за сообщениями
