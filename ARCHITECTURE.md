# Архитектура системы анализа техники катания на лыжах

## 📋 Обзор

Система автоматизирует анализ техники катания на горных лыжах через обработку видео и сравнение с эталоном. Система готова к интеграции в бизнес-сервис.

## 🏗️ Текущая архитектура

### Модульная структура

```
ski_analyzer/
├── core/              # Основные модули обработки
│   ├── pose_extractor.py      # Извлечение позы (YOLO)
│   ├── angle_calculator.py    # Вычисление углов
│   ├── data_processor.py      # Сглаживание и ресемплинг
│   ├── template_builder.py    # Построение эталона
│   ├── analyzer.py            # Анализ и рекомендации
│   └── pipeline.py            # Единый pipeline
├── config/            # Конфигурация
│   └── settings.py
└── utils/             # Утилиты
```

### Pipeline обработки

1. **Извлечение позы** (`PoseExtractor`)
   - Использует YOLOv8-pose для детекции ключевых точек
   - Вход: видео файл
   - Выход: CSV с landmarks (17 точек COCO формата)

2. **Вычисление углов** (`AngleCalculator`)
   - Вычисляет углы коленей и корпуса
   - Вход: landmarks CSV
   - Выход: angles CSV

3. **Обработка данных** (`DataProcessor`)
   - Сглаживание (Savitzky-Golay фильтр)
   - Ресемплинг до 100 точек (нормализация по фазе движения)
   - Вход: angles CSV
   - Выход: resampled CSV

4. **Построение эталона** (`TemplateBuilder`)
   - Агрегирует множество примеров
   - Вычисляет mean и std для каждого угла
   - Вход: множество resampled CSV
   - Выход: template CSV

5. **Анализ** (`SkiAnalyzer`)
   - Сравнивает пользователя с эталоном
   - Генерирует рекомендации
   - Вход: user resampled CSV + template
   - Выход: отчет с рекомендациями

## 🚀 Использование

### Базовое использование

```python
from ski_analyzer.core.pipeline import SkiAnalysisPipeline

# Создаем pipeline
pipeline = SkiAnalysisPipeline()

# Обрабатываем видео
files = pipeline.process_video("video.mp4", save_intermediate=True)

# Анализируем
result = pipeline.analyze_user_video("video.mp4")
print(result['analysis']['recommendations'])
```

### Через командную строку

```bash
# Обработка видео
python process_video.py video.mp4

# Обработка с анализом
python process_video.py video.mp4 --analyze

# Построение эталона
python process_video.py --build-template
```

## 💼 Рекомендации для бизнеса

### Подход 1: Эталон + LLM (РЕКОМЕНДУЕТСЯ)

**Преимущества:**
- ✅ Прозрачность: пользователь видит сравнение с эталоном
- ✅ Объяснимость: легко объяснить почему дана рекомендация
- ✅ Гибкость: LLM может генерировать персонализированные рекомендации
- ✅ Масштабируемость: один эталон для всех пользователей
- ✅ Низкие затраты на обучение: не нужна большая ML модель

**Архитектура:**
```
Видео → Pipeline → Углы → Сравнение с эталоном → Метрики отклонений → LLM → Рекомендации
```

**Интеграция LLM:**
```python
def generate_llm_recommendations(analysis_result, user_profile=None):
    """
    Генерирует рекомендации через LLM на основе анализа
    """
    prompt = f"""
    Проанализируй технику катания на лыжах:
    
    Отклонения от эталона:
    {format_analysis(analysis_result)}
    
    Профиль пользователя: {user_profile}
    
    Дай конкретные рекомендации для улучшения техники.
    """
    
    # Вызов LLM API (OpenAI, Anthropic, etc.)
    recommendations = llm_api.generate(prompt)
    return recommendations
```

**Когда использовать:**
- Стартап/ранний этап
- Нужна быстрая разработка MVP
- Важна объяснимость для пользователей
- Ограниченный бюджет на ML

### Подход 2: ML модель (для будущего)

**Преимущества:**
- ✅ Может учитывать сложные паттерны
- ✅ Может работать без эталона
- ✅ Потенциально более точные рекомендации

**Недостатки:**
- ❌ Требует большого датасета с разметкой
- ❌ Сложнее в разработке и поддержке
- ❌ Меньше объяснимости

**Когда использовать:**
- Есть большой размеченный датасет (1000+ видео)
- Есть ресурсы на обучение и поддержку ML модели
- Нужны сложные паттерны, которые эталон не покрывает

### Гибридный подход (ОПТИМАЛЬНО)

**Комбинация эталона и ML:**
1. Эталон для базовых рекомендаций (быстро, прозрачно)
2. ML модель для сложных случаев и персонализации
3. LLM для генерации текстовых рекомендаций

```
Видео → Pipeline → Углы → [Эталон сравнение + ML модель] → LLM → Рекомендации
```

## 🔧 Интеграция в сервис

### API структура (рекомендуется)

```python
# api/main.py (FastAPI пример)
from fastapi import FastAPI, UploadFile, File
from ski_analyzer.core.pipeline import SkiAnalysisPipeline

app = FastAPI()
pipeline = SkiAnalysisPipeline()

@app.post("/analyze")
async def analyze_video(video: UploadFile = File(...)):
    # Сохраняем видео
    video_path = save_uploaded_file(video)
    
    # Обрабатываем
    result = pipeline.analyze_user_video(video_path)
    
    # Интеграция с LLM (опционально)
    if USE_LLM:
        result['llm_recommendations'] = generate_llm_recommendations(
            result['analysis']
        )
    
    return result
```

### База данных

**Рекомендуемая схема:**
- `users` - пользователи
- `videos` - загруженные видео
- `analyses` - результаты анализа
- `recommendations` - рекомендации
- `templates` - эталоны (для разных уровней/стилей)

### Масштабирование

1. **Очередь задач** (Celery/RQ) для обработки видео
2. **Кэширование** эталонов и промежуточных результатов
3. **CDN** для хранения видео
4. **GPU серверы** для YOLO обработки

## 📊 Метрики для бизнеса
