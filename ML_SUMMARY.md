# Краткая сводка: Обучение ML модели

## ✅ Ответы на ваши вопросы

### 1. Как генерировать видео с разными признаками?

**✅ Решение готово:** Используйте `VideoAugmenter` из `ski_analyzer.ml.dataset_generator`

**Что делает:**
- Изменяет цвет костюма (hue shift)
- Меняет масштаб (симуляция роста)
- Изменяет яркость/насыщенность
- Добавляет повороты и обрезки

**Пример:**
```bash
python augment_dataset.py --input Ski.Videos/Professional --output data/augmented --variations 5
```

**Результат:** 1 видео → 5 вариаций с разными параметрами

### 2. Сколько нужно видео?

**Минимум:**
- 20-30 видео для первого эксперимента
- 50-100 видео для рабочей модели
- 200-500 видео для хорошей модели

**С аугментацией (5x):**
- 20 видео → 100 видео
- 50 видео → 250 видео
- 100 видео → 500 видео

**Рекомендация:** Начните с 20-30 видео, увеличьте до 100-150 через аугментацию.

### 3. С чего начать, если ничего не понимаешь?

**План на первую неделю:**

1. **День 1-2:** Подготовка данных
   - Собрать 20-30 видео
   - Разметить (хорошее/плохое)
   - Увеличить через аугментацию

2. **День 3-4:** Изучение PyTorch
   - Пройти официальные туториалы

3. **День 5-7:** Первая модель
   - Использовать готовую модель (X3D, ResNet)
   - Обучить на своих данных
