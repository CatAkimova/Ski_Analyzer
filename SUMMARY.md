## 💡 Выбор подхода для бизнеса

### Рекомендуется: **Эталон + LLM**

**Почему:**
- ✅ Быстрая разработка MVP (1-2 месяца)
- ✅ Низкие затраты (нет необходимости в обучении ML модели)
- ✅ Прозрачность (пользователь видит сравнение с эталоном)
- ✅ Объяснимость (легко объяснить рекомендации)
- ✅ Гибкость (LLM может генерировать персонализированные советы)

**Когда переходить на ML:**
- Когда соберете большой размеченный датасет (1000+ видео)
- Когда нужны сложные паттерны, которые эталон не покрывает
- Когда есть ресурсы на обучение и поддержку ML модели

## 🚀 Быстрый старт

1. **Построить эталон** (если еще не сделано):
   ```bash
   python process_video.py --build-template
   ```

2. **Обработать видео пользователя**:
   ```bash
   python process_video.py "video.mp4" --analyze
   ```

3. **Использовать в коде**:
   ```python

   pipeline = SkiAnalysisPipeline()
   result = pipeline.analyze_user_video("video.mp4")
   ```
